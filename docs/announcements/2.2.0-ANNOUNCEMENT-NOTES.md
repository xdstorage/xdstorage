## Headline items (lead with these)

1. **Backup API** — `storage.backupTo(Path)`: a consistent point-in-time copy of a LIVE
   storage (task 15; pulled forward from 2.3.0 by the PRODUCT_REVIEW as non-negotiable).
   Restore contract = close → open the copy (task 19's proved walkthrough). *User meaning:
   "back up while running" finally has a supported answer — no more copy-while-closed
   folklore.* Writer TODO: the GUIDE § backup section + the EMBEDDING operational note
   (what is consistent, what is not, the lock interplay).

2. **The operations CLI** — `xdstorage-tools.jar`: `verify` (task 26's integrity walk),
   `backup` (task 15), `inspect`, `migrate` (task 16; the PRODUCT_REVIEW high-priority).
   *User meaning: pipelines/agents/shells operate the storage without writing Java; the
   after-a-power-loss recipe becomes typed commands instead of prose.*

3. **Run on a JRE (AOT wrapper generation)** — task 08, the discovery's explicit demand
   ("I need to use it with JRE, not JDK!!!"): a Maven plugin generates the wrappers at
   BUILD time; runtime codegen stays as the fallback; a JRE-only container runs the demo;
   native-image smoke. *User meaning: the JDK-at-runtime requirement (the current EMBEDDING
   § Codegen hard rule) becomes optional — AOT for production images, codegen for dev.*

4. **The consistency core on standard primitives** — task 01 (P0, 5–8 sessions): the
   hand-rolled spin/notify lock and latch machinery is replaced by
   `ReentrantReadWriteLock`/`Condition`/`StampedLock`; the disabled B+Tree/multi-tree
   invariant tests come back into the gate. *User meaning: fewer exotic concurrency
   behaviors to reason about; the correctness estate grows.* Prerequisite per the plans:
   task 03 (property tests) is the acceptance gate for task 01.

5. **The memory train (W-4d)** — task 05: disk-anchored scans (iterate from base+journal,
   not the cache), record-cache eviction (LRU over committed/unlocked/non-infra — the F-3
   thaw), bounded resource retention during transactions. *User meaning: the memory profile
   stops growing with the working set; large-scan containers stop OOM-ing.* Design round
   FIRST (the house rule); the off-heap decision rides here.
